# Search Certification

Status: deterministic task ranking and route selection pass automated tests. Full live-workspace entity search is not certified without authenticated QA.

Existing priority remains actions, recent/frequent matching work, other current-workspace records, pages, then settings. Phase 3 adds labels/keywords for existing actions and direct destinations; it adds no index, fetch, repository or query. Export Report, Generate Brochure, Invite Team, Schedule Viewing and Send WhatsApp point to existing tools. Upload Photos and Update Company find their existing parent workflows without claiming to perform those operations.

Current operation forms may still require selecting the record again.
