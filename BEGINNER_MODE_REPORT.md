# Beginner Mode Report

No new mode or feature was created. Existing forms and labels were reorganized for a broker unfamiliar with CRM software.

- Property entry visits four core sections before save; optional details remain accessible. Step buttons wrap and keep visible labels instead of requiring horizontal browsing.
- Lead entry focuses on contact, requirements, then review. Lead source, property matching and assignment remain available as optional details. Team workflows are preserved.
- Save feedback brings existing next steps above the record panels. Property suggests brochure, buyers and viewing; lead suggests follow-up, property recommendations and viewing; deal suggests agreement, follow-up and performance.
- Next-step links explain that they open a tool for review. They do not claim an action has executed.
- Property photos say preview on this device, not upload. Inactive drag/video/tour controls and the duplicate picker entry were removed.
- Search has broker task labels and a plain preview hint. Profile recovery is labeled Reset Password.
- Landing copy states the daily job rather than a timed AI hiring promise or unverified superlative.

Remaining: record matching scores, some specialist terminology, optional browser-only data and incomplete panels need usability testing. Do not rename an automation as Automatic Follow-up unless it actually follows up; workflows can perform other jobs. Do not claim a new beginner mode or certify all dynamic copy as jargon-free.
