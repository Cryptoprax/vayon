# Daily Broker Simulation

This is a source-based task simulation, not a live day with customer data. No messages, invitations, uploads, campaigns, deals or password recovery emails were submitted.

| Moment | Broker intention | Existing path | Interruption found | Result / remaining work |
|---|---|---|---|---|
| Morning login | Access today's work | Login to Dashboard | Identity/session/workspace recovery can interrupt | Existing auth preserved; signed-in QA required |
| Review dashboard | Pick next task | Start today's work | Empty figures can look like a failed setup | Existing guidance retained, no fabricated metrics |
| Call buyers | Continue a conversation | Context action / Communications | Broad AI workspace detour | Existing conversation tool now opens directly; actual calling support is not implied |
| Update property | Correct listing details | Record Edit | Long optional sequence and horizontal step browsing | Five default navigation selections; optional sections retained |
| Schedule viewing | Arrange a visit | Schedule Viewing / existing Site visits form | Generic calendar detour | Direct task entry; existing form still validates and may require record selection |
| Generate campaign | Prepare marketing | Existing campaign tool | Creative hub category selection; generation may be unavailable | Direct destination; no new generation capability |
| Close deal | Update deal and continue hand-off | Existing deal editor | Unclear next step; incomplete agreement/referral capability | Agreement/follow-up/performance links close to feedback; actual closing/exports not certified |
| Invite colleague | Share work | Invite Team / Members | Task terminology did not match directory label | Exact search shortcut; real invitation not sent |
| Finish work | Confirm work and return later | Existing records/history/sign out | Persistence uncertainty for previews or interrupted save | Preview-only and retry guidance clarified; no extra summary/dashboard added |

Solo broker: skip optional matching/team fields until relevant. Five-person agency: use optional assignment and existing member invitations. 25-person owner: verify cross-team visibility and approvals with actual roles; do not bypass restrictions for convenience.

Unresolved interruptions: no authenticated QA state, missing authoritative approval indexing, capped/list-based search, photo preview persistence, disabled generation/export capabilities, incomplete specialist panels and destination context prefill. Removing these through invented services or optimistic success states would violate this phase's rules.
