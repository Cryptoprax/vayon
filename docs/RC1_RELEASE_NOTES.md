# VAYON RC1 release notes

RC1 is a closed-beta candidate focused on reliability and launch verification. It introduces no new product features, redesigns, or architectural changes.

## Candidate scope

- Public marketing, signup, authentication, onboarding, workspace, dashboard, CRM, Copilot, Workflow Planner, billing, and Paddle integration surfaces are included in the candidate.
- Preview-and-confirm governance remains the workflow execution boundary.
- Existing RBAC, organization/workspace isolation, entitlements, billing synchronization, and provider boundaries are preserved.
- Production build and 1,292 automated regression tests pass.

## Release status

The code candidate is locally green, but closed-beta release approval is withheld pending live authenticated journeys, Paddle sandbox certification, visual regression, accessibility, performance, and infrastructure sign-off. See `RC1_VALIDATION_REPORT.md` and `RC1_KNOWN_ISSUES.md`.
