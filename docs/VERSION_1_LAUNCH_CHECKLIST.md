# VAYON Version 1.0 Launch Checklist

Record owner, UTC verification time, environment, evidence link and outcome for every item. Never paste credentials into this document.

- [ ] Production domain and canonical URL verified
- [ ] DNS records and propagation verified
- [ ] SSL/TLS certificate, renewal and HTTPS redirect verified
- [ ] Google Workspace production project and OAuth consent verified
- [ ] SPF verified
- [ ] DKIM verified
- [ ] DMARC policy and reporting verified
- [ ] Stripe live mode, products, prices, tax and webhook signatures verified
- [ ] Razorpay live mode, plans, GST and webhook signatures verified
- [ ] OpenAI billing, quota, model access and health verified
- [ ] Supabase production project, migrations, RLS, RPCs, indexes and storage verified
- [ ] Database and storage backups enabled
- [ ] Isolated restore drill completed and recovery objectives recorded
- [ ] Monitoring, structured logs and provider dashboards verified
- [ ] Availability, security, queue and background-job alerts verified
- [ ] Consent-aware analytics verified
- [ ] Support email delivery, ownership and escalation verified
- [ ] Rate limits verified at public and expensive entry points
- [ ] Authenticated cross-browser and accessibility evidence attached
- [ ] Rollback owner and incident commander confirmed
- [ ] Investor/demo environment visibly labeled and isolated from production tenants
