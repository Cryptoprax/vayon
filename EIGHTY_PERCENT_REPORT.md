# Eighty percent rule review

No measured workflow timing, task count baseline, or controlled completion study exists for this phase. An 80% manual-work reduction cannot be certified for any workflow below. This is an evaluation threshold, not a score shown to customers.

| Daily workflow | Existing functionality reused | Manual work that remains |
| --- | --- | --- |
| Morning planning | Dashboard snapshot and calendar | Reconcile overdue work, notifications, and incomplete records |
| Lead follow-up | Lead contacts, tasks, communications | Select recipient, verify history, compose/review and send |
| Property work | Property wizard and editing | Enter and verify facts; persist approved media using supported tools |
| Client meetings | Linked leads, calendar and site visits | Confirm availability, participants, property, and outcome |
| Marketing | Existing campaign drafts, documents and creative editor | Select project, verify copy and assets; rendering/publishing availability varies |
| Negotiation | Deal stages and task workflows | Record offers, confirm commitments, request approvals |
| Closing | Existing document preparation | Review agreements, payments, signatures and legal requirements |
| Reporting | Existing analytics and CSV export | Interpret coverage and reconcile source records |
| Workspace setup | Existing settings and invitations | Configure access and integrations and obtain consent |
| AI assistance | Existing task workspace | Verify actual artifacts and approve supported actions |

Discoverability was improved through the Morning Brief, one visible next step, and factual search descriptions. No new automation, reminder service, publishing capability, or AI provider was added to close these gaps. Savings require future observed evidence, not inferred clicks or fabricated hours.
